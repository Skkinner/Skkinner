### 🧪 Featured Project

#### **Deep Learning-Based Depression Detection from Brain MRI**
- **Architecture**: Implemented a multimodal late-fusion architecture combining a **3D CNN imaging branch** with a **Multi-Layer Perceptron (MLP) clinical branch**.
- **Normative Modeling**: Designed a 3D convolutional autoencoder for unsupervised pretraining on Healthy Control scans to establish structural baselines.
- **Explainability**: Integrated **Grad-CAM** visualizations to highlight critical neurological regions (e.g., hippocampus, prefrontal cortex).
- **Impact**: Achieved **97% accuracy (0.9870 AUC)** on an independent test set. Deployed via FastAPI and Next.js.
